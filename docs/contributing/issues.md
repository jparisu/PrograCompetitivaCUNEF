# Sugerencias e incidencias

No hace falta saber programar ni usar Git para ayudar. Si ves una errata, algo que no
funciona, o tienes una idea para mejorar el material, cuéntanoslo en GitHub.

## ¿Qué canal uso?

<div class="grid cards" markdown>

-   :material-bug: __Incidencias (Issues)__

    ---

    Para algo **concreto y accionable**: una errata, un enlace roto, un error en el
    código, un ejemplo equivocado o una petición clara ("falta el algoritmo X").

    [:octicons-arrow-right-24: Crear una incidencia](https://github.com/jparisu/PrograCompetitivaCUNEF/issues/new/choose)

-   :material-forum: __Conversación (Discussions)__

    ---

    Para **ideas, dudas y debate**: proponer un tema, preguntar cómo se hace algo, o
    discutir cómo organizar una parte de la web antes de abrir una incidencia.

    [:octicons-arrow-right-24: Abrir una conversación](https://github.com/jparisu/PrograCompetitivaCUNEF/discussions)

</div>

## Cómo escribir una buena incidencia

1. **Busca antes** en las [incidencias existentes](https://github.com/jparisu/PrograCompetitivaCUNEF/issues)
   por si ya está reportada.
2. Pon un **título claro** que resuma el problema.
3. Explica **qué esperabas** y **qué ocurrió**, y en qué **página** (pega el enlace).
4. Si es un error de código, indica el **algoritmo**, el **lenguaje** y la **versión**
   (`full` / `clean` / `contest`), y el caso de entrada que falla.

!!! tip "¿Prefieres arreglarlo tú?"
    Si te animas a corregirlo, mejor aún: sigue [Cómo contribuir](index.md) y abre un
    Pull Request. Puedes enlazar la incidencia desde el PR.
