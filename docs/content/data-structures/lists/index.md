Las **listas** (o *vectores*) guardan una secuencia de elementos accesibles por su
posición (índice). Son la estructura más básica y la base de casi todo lo demás.

**Por documentar:** acceso por índice, añadir/eliminar al final, recorrer, tamaño, y las
diferencias entre `vector` (C++) y `list` (Python).
