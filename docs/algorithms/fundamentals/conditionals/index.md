# Condicionales

!!! info "Metadatos"
    **Tipo:** Técnica · **Nivel:** Base · **Dificultad:** 0.7

Los **condicionales** permiten que el programa **decida** qué hacer según se cumpla o no
una condición. Son la base de toda la lógica: "si pasa esto, haz aquello; si no, haz lo
otro".

Las piezas son las mismas en todos los lenguajes:

- **`if`** — ejecuta un bloque **solo si** la condición es verdadera.
- **`else`** — qué hacer **en caso contrario**.
- **`else if` / `elif`** — encadenar varias condiciones.

Lo que cambia es la **sintaxis**. Elige tu lenguaje:
