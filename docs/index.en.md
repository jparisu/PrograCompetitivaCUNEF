# Competitive Programming

Learn to program in **C++** and **Python** and go on to compete in **ICPC**-style contests.
Clear explanations, ready-to-copy code, and a cheatsheet for contest day.

[Start here :material-rocket-launch:](start/onboarding.md){ .md-button .md-button--primary }

## The contests

These are the contests we aim for. Train with this material and get a team together.

<div class="grid cards contest-grid" markdown>

-   [![ICPC](resources/images/icpc.png){ .contest-logo }](https://icpc.global/)

    __ICPC__

    The largest collegiate programming contest in the world: teams of three solve
    algorithmic problems against the clock.

    [Official site](https://icpc.global/){ .md-button }

-   [![SWERC](resources/images/swerc.png){ .contest-logo }](https://swerc.eu/)

    __SWERC__

    The ICPC regional for Southwestern Europe (Spain, France, Portugal, Italy…).
    CUNEF's gateway to the world finals.

    [Official site](https://swerc.eu/){ .md-button }

-   [![Ada Byron](resources/images/adabyron.png){ .contest-logo }](https://ada-byron.es/2026/nac/)

    __Ada Byron__

    A competitive programming contest in Spain, with local rounds and a national final.

    [Official site](https://ada-byron.es/2026/nac/){ .md-button }

</div>
