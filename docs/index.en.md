# Competitive Programming CUNEF

This project helps CUNEF students program in **C++** and **Python** and compete in
**ICPC**-style contests. You will find explanations, ready-to-copy code templates, and a
cheatsheet to take to the contest.

!!! tip "Where do I start?"
    If you have never competed, start at [Start here](onboarding.md) and follow the
    **Base** level. If you already have experience, jump to the level you need.

## Levels

The material is organized by difficulty, like a staircase towards the ICPC:

| Level | For whom | Example |
|-------|----------|---------|
| **Base** | First contact with programming | [Loops](algorithms/fundamentals/loops/index.md) |
| **Beginner** | First contest problems | [Binary search](algorithms/searching/binary-search-array/index.md) |
| **Intermediate** | Data structures and graphs | [Fenwick tree](algorithms/data-structures/fenwick-tree/index.md) |
| **Advanced** | Powerful techniques | [Bitmask DP (TSP)](algorithms/dynamic-programming/bitmask-tsp/index.md) |
| **Expert** | Elite topics | [Convex hull](algorithms/geometry/convex-hull/index.md) |

## How to use each page

- Every algorithm ships code in **C++ and Python**, in tabs.
- Use the **copy** button on each block to paste it straight into the online judge.
- Check the [Techniques](techniques/binary-search/index.md) to understand the recurring
  patterns across problems.
