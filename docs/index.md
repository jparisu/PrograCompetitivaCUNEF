# Programación Competitiva CUNEF

Este proyecto nace para ayudar a los alumnos de CUNEF a programar en **C++** y **Python**
y competir en concursos de programación tipo **ICPC**. Encontrarás explicaciones,
plantillas de código listas para copiar y un chuletario para llevar al concurso.

!!! tip "¿Por dónde empiezo?"
    Si nunca has competido, empieza por [Empezar aquí](onboarding.md) y sigue el nivel
    **Base**. Si ya tienes experiencia, salta directamente al nivel que necesites.

## Niveles

El material está organizado por dificultad, como una escalera hacia el ICPC:

| Nivel | Para quién | Ejemplo |
|-------|------------|---------|
| **Base** | Primer contacto con la programación | [Bucles](algorithms/fundamentals/loops/index.md) |
| **Principiante** | Primeros problemas de concurso | [Búsqueda binaria](algorithms/searching/binary-search-array/index.md) |
| **Intermedio** | Estructuras de datos y grafos | [Árbol de Fenwick](algorithms/data-structures/fenwick-tree/index.md) |
| **Avanzado** | Técnicas potentes | [DP con máscaras (TSP)](algorithms/dynamic-programming/bitmask-tsp/index.md) |
| **Experto** | Temas de élite | [Envolvente convexa](algorithms/geometry/convex-hull/index.md) |

## Cómo usar cada página

- Cada algoritmo trae el código en **C++ y Python**, en pestañas.
- Usa el botón de **copiar** de cada bloque para pegarlo directamente en el juez online.
- Consulta las [Técnicas](techniques/binary-search/index.md) para entender los patrones
  que se repiten entre problemas.
